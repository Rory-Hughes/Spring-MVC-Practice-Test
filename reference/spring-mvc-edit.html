Debug by symptom

  • 404 on Edit. Compare the generated link, the GET mapping and the selected row ID.
  • 405 on Save. Compare the form method and action with the POST mapping.
  • Blank table. Check the service results, model key and th:each expression.
  • Form rendering fails. Match the form object name across GET, POST and th:object. Check that the error branch restores the ID and other supporting data.
  • Errors missing. Check @Valid, the position of BindingResult and the property names in th:field and th:errors.
  • Extra row or wrong row. Check the selected URL ID and that the service saves the retrieved entity.
